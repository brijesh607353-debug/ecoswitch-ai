# Screenshots

This folder contains screenshots used in the project README and documentation.

---

## How to Add Screenshots

1. **Take a screenshot** of your running app (full page or focused on a feature)
2. **Optimise it** — keep files under 500 KB:
   - PNG for UI screenshots (lossless)
   - JPG for photos or complex images
   - Use [Squoosh](https://squoosh.app/) or `pnpm imagemin` to compress
3. **Name it clearly** using kebab-case: `feature-name.png`
4. **Reference it in the README**:

```markdown
![Feature description](./screenshots/feature-name.png)
```

---

## Naming Convention

| Filename | Contents |
|----------|---------|
| `hero.png` | Main landing page or dashboard — used as the README hero image |
| `onboarding.png` | Onboarding or sign-up flow |
| `dashboard.png` | Main dashboard view |
| `plan-comparison.png` | Energy plan comparison screen |
| `mobile-*.png` | Mobile/responsive views |
